# Perfume Sales Performance | Summary

## 📊 Project Overview
[cite_start]An interactive **Power BI** dashboard [cite: 17, 53] analyzing a **Kaggle dataset** of over 1,000 perfume products to identify pricing trends and market outliers. This project was developed as part of my **B.Sc. [cite_start]Data Science** curriculum [cite: 9, 37] to demonstrate proficiency in end-to-end data storytelling and visualization.

## 🚀 Key Features
* **Advanced Visualization:** Engineered a high-fidelity **dark-mode UI** utilizing custom hex palettes and "outer glow" effects for enhanced readability.
* **Statistical Analysis:** Implemented a **Dynamic Scatter Plot** with integrated zoom sliders to visualize the correlation between price points and units sold.
* **UX Optimization:** Resolved categorical label truncation by transitioning to a **horizontal bar chart hierarchy**, ensuring 100% data accessibility for long product names.
* [cite_start]**Data Engineering:** Performed complex data cleaning, normalization, and multi-step transformations using **Power Query**[cite: 24, 63].

## 🛠️ Tech Stack
**Power BI**: Dashboard design and DAX measures.
**Power Query**: ETL (Extract, Transform, Load) processes.
**Microsoft Excel**: Data source management and initial data inspection.
